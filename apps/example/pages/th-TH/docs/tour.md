# กิจกรรมที่รู้ว่าตอนนี้ที่คุณอยู่เป็นเวลาเท่าไร

[[toc]]

โพสต์กิจกรรมในเมืองของคุณ ใครก็ได้ไม่ว่าอยู่ที่ไหนจะเห็นเวลาเริ่มตามนาฬิกา**ของคุณ**และ**ของเขาเอง**
เป็นภาษาของเขา ไม่ต้องคำนวณเขตเวลา ไม่ต้องถามว่า "หนึ่งทุ่มของฉันหรือของคุณ" {.lead}

![โลโก้ Void](/void.svg)

## ลองใช้ดู {#try-it}

1. โพสต์กิจกรรมเป็นภาษาของคุณเอง
2. เปลี่ยนภาษาที่ด้านบน: กิจกรรมจะเปลี่ยนตามคุณ
3. จองที่นั่ง :tada:

> [!TIP] เขตเวลาของคุณ
> หน้านี้รู้เขตเวลาของคุณจากเบราว์เซอร์: <span data-your-zone></span>

## โพสต์เป็นภาษาของคุณ {#post}

เขียนชื่อและรายละเอียดแบบที่คุณพูดตามปกติ ผู้อ่านจะเห็นตามที่คุณเขียน พร้อมระบุว่าเป็นภาษาอะไร
เบราว์เซอร์และโปรแกรมอ่านหน้าจอของเขาจึงอ่านได้ถูกต้อง

::: tip เขียนแบบที่คุณพูด
ใช้คำของคุณเองและวิธีเขียนวันที่แบบของคุณ ผู้อ่านจะเห็นคำของคุณตามที่คุณเขียน
:::

::: warning เลือกเมืองของกิจกรรม
ตั้งเมืองที่จัดกิจกรรม ไม่ใช่เมืองที่คุณอยู่ตอนนี้ ทุกเวลาคำนวณจากเมืองนั้น
:::

> [!NOTE] ภาษาก็ถูกบันทึกด้วย
> แต่ละกิจกรรมบันทึกภาษาที่ใช้เขียน เบราว์เซอร์และโปรแกรมอ่านหน้าจอของผู้อ่านจึงอ่านเป็นภาษานั้น ไม่ว่าหน้าเว็บรอบ ๆ จะเป็นภาษาอะไร

## ทุกเวลาแสดงสองแบบ {#times}

แต่ละกิจกรรมแสดงเวลาเริ่มตามสถานที่จัด แสดงอีกครั้งตามนาฬิกาของคุณ และบอกว่าอีกนานเท่าไร
เวลาออมแสงคำนวณตามวันที่จัดกิจกรรม ไม่ใช่ตามวันนี้[^dst] นี่คือตลาดนัดกลางคืนในกรุงเทพฯ
เป็นภาษาและเขตเวลาของคุณ:

<EventTime startsAt="2027-03-06T18:30:00+07:00[Asia/Bangkok]" />

<dl>
  <dt>นาฬิกาของกิจกรรม</dt>
  <dd>เวลาที่สถานที่จัดกิจกรรม: เวลาที่เขียนไว้บนโปสเตอร์</dd>
  <dt>นาฬิกาของคุณ</dt>
  <dd>ช่วงเวลาเดียวกันที่ที่คุณอยู่: เวลาที่คุณต้องออกจากบ้าน</dd>
</dl>

> [!IMPORTANT] นาฬิกาของกิจกรรมมาก่อน
> เวลาเริ่มคือเวลาตามนาฬิกาของกิจกรรมเอง เวลาของคุณคำนวณจากเวลานั้น ไม่ใช่กลับกัน

::: info ทำไมต้องมีทั้งสองแบบ
<mark>คนที่อยู่อีกเมืองหนึ่ง</mark>ต้องการทั้งสองแบบ: เวลาบนโปสเตอร์ และเวลาบนโทรศัพท์ของตัวเอง
:::

## บันทึกครั้งเดียว แสดงได้ทุกภาษา {#stored}

สิ่งที่คุณโพสต์ถูกบันทึกเป็นข้อมูลธรรมดา ไม่ใช่ข้อความในภาษาของคุณ ได้แก่ เวลาเริ่มตามนาฬิกาของเมืองนั้นพร้อมเขตเวลาของเมือง
ช่วงเวลาเดียวกันใน UTC และจำนวนที่นั่ง หน้าของแต่ละกิจกรรมแสดงข้อมูลนี้ใต้หัวข้อ **บันทึกเป็น** ลองเปลี่ยนภาษาที่ด้านบน
ทุกอย่างในหน้าจะเปลี่ยนไป ยกเว้นกล่องนั้น

| อะไร             | บันทึกเป็น                                   | แสดงเป็น                |
| ---------------- | ----------------------------------------- | ---------------------- |
| เวลาเริ่ม          | `2027-03-06T18:30:00+07:00[Asia/Bangkok]` | เป็นภาษาของคุณ           |
| เวลาเดียวกันใน UTC | `2027-03-06T11:30:00Z`                    | ไม่แสดง ใช้สำหรับเรียงลำดับ |
| ที่นั่ง              | `40`                                      | เป็นตัวเลขของภาษาของคุณ   |

::: details หน้าตาของกิจกรรมเมื่อบันทึกแล้ว
```json {4} :line-numbers
{
  "id": "6f1c…",
  "title": "Night market",
  "starts_at": "2027-03-06T18:30:00+07:00[Asia/Bangkok]",
  "starts_at_utc": "2027-03-06T11:30:00Z",
  "seats": 40,
  "locale": "th-TH"
}
```
:::

::: danger อย่าบันทึกข้อความที่จัดรูปแบบแล้ว
ข้อความอย่าง "6 มี.ค. 18:30 น." ถูกต้องในภาษาเดียวและเขตเวลาเดียวเท่านั้น ให้บันทึกข้อมูล แล้วจัดรูปแบบให้ผู้อ่านแต่ละคน:

```ts
const saved = start.toLocaleString("en-US"); // [!code --]
const saved = start.toString(); // [!code ++]
const shown = start.toLocaleString(locale); // [!code focus]
const sorted = start.toLocaleString(); // [!code error]
const guessed = new Date(start.epochMilliseconds); // [!code warning]
```
:::

> [!WARNING] โทรศัพท์บางรุ่นยังไม่มี Temporal
> iPhone รุ่นปัจจุบันยังไม่มี Temporal ในตัว แอปจึงนำมาเองบนเครื่องเหล่านั้น เวลาที่แสดงเหมือนกัน

> [!CAUTION] ย้ายกิจกรรมไปอีกเมือง
> การเปลี่ยนเขตเวลาของกิจกรรมจะเปลี่ยนเวลาที่กิจกรรมเกิดขึ้นสำหรับทุกคน ให้เปลี่ยนเวลาไปพร้อมกัน

คัดลอกโค้ดได้ด้วยปุ่มของมัน หรือเลือกแล้วกด <kbd>Ctrl</kbd> + <kbd>C</kbd>

## จัดรูปแบบให้คุณ {#formatted}

ทุกค่าด้านล่างเป็น island `<Fmt>` (`src/docs/Fmt.tsx`) จึงจัดรูปแบบให้คุณ เป็นภาษาของหน้านี้:

- ตัวเลข: <Fmt num="1234567.891" />
- เงิน: <Fmt money="1299" currency="THB" />
- เวลาตามนาฬิกาของสถานที่: <Fmt when="2027-03-06T18:30:00+07:00[Asia/Bangkok]" />
- เวลาเดียวกันตามนาฬิกาของคุณ: <Fmt yours="2027-03-06T18:30:00+07:00[Asia/Bangkok]" />
- อีกนานเท่าไร: <Fmt ago="2027-03-06T18:30:00+07:00[Asia/Bangkok]" />
- ชื่อภาษาในภาษาของคุณ: <Fmt langs />

กลับไปที่[ทุกเวลาแสดงสองแบบ](./tour.md#times) หรือ[ดูกิจกรรมที่กำลังจะมาถึง](../events)

[^dst]: กรุงเทพฯ ไม่มีเวลาออมแสง แต่เมืองที่มีจะปรับนาฬิกาในวันที่ของตัวเอง เวลาที่แสดงสำหรับวันหนึ่งในเดือนกรกฎาคมจึงคำนวณตามเดือนกรกฎาคม
