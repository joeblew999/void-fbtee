# อีเวนต์ที่รู้ว่าตอนนี้ที่ที่คุณอยู่เป็นเวลากี่โมง

[[toc]]

โพสต์อีเวนต์ในเมืองของคุณ ไม่ว่าใคร ที่ไหน ก็จะเห็นเวลาเริ่มต้นตามนาฬิกา**ของคุณ**และ**ของพวกเขา** ในภาษาของพวกเขาเอง ไม่ต้องคำนวณเขตเวลา ไม่ต้องสงสัยว่า "นี่หมายถึง 1 ทุ่มของฉันหรือของคุณ?" {.lead}

![โลโก้ The Void](/void.svg)

## ลองใช้งาน {#try-it}

1. โพสต์อีเวนต์ในภาษาของคุณเอง
2. สลับภาษาที่ด้านบน: อีเวนต์จะเปลี่ยนตามคุณไปด้วย
3. จองที่นั่ง :tada:

> [!TIP] เขตเวลาของคุณ
> หน้านี้ทราบเขตเวลาของคุณจากเบราว์เซอร์: <span data-your-zone></span>

## โพสต์ในภาษาของคุณ {#post}

เขียนชื่อเรื่องและคำอธิบายตามที่คุณพูด ผู้อ่านจะเห็นตามที่คุณเขียน โดยมีการระบุภาษาที่ใช้ เพื่อให้เบราว์เซอร์และโปรแกรมอ่านหน้าจออ่านได้อย่างถูกต้อง

::: tip เขียนตามที่คุณพูด
ใช้คำพูดและวิธีเขียนวันที่ในแบบของคุณเอง ผู้อ่านจะเห็นข้อความตามที่คุณเขียนไว้
:::

::: warning เลือกเมืองที่จัดอีเวนต์
ตั้งค่าเป็นเมืองที่จัดอีเวนต์จริง ไม่ใช่เมืองที่คุณอยู่ในตอนนี้ เวลาทั้งหมดจะถูกคำนวณจากเมืองนั้น
:::

> [!NOTE] ภาษาจะถูกบันทึกไว้ด้วย
> อีเวนต์แต่ละรายการจะบันทึกภาษาที่ใช้เขียนไว้ด้วย เพื่อให้เบราว์เซอร์และโปรแกรมอ่านหน้าจอของผู้อ่านอ่านในภาษานั้นได้ ไม่ว่าหน้าเว็บโดยรอบจะเป็นภาษาใดก็ตาม

## ทุกเวลา แสดงสองแบบ {#times}

อีเวนต์แต่ละรายการจะแสดงช่วงเวลาตั้งแต่เริ่มจนจบ ณ สถานที่จัดงาน แสดงอีกครั้งตามนาฬิกาของคุณเอง และแสดงว่าอีกนานเท่าไรจึงจะถึงเวลา
ระบบออมแสง (Daylight saving) จะคำนวณตามวันที่จัดอีเวนต์ ไม่ใช่วันนี้[^dst] นี่คือตลาดกลางคืนในกรุงเทพฯ ในภาษาและเขตเวลาของคุณ:

<EventTime startsAt="2027-03-06T18:30:00+07:00[Asia/Bangkok]" endsAt="2027-03-06T21:30:00+07:00[Asia/Bangkok]" />

<dl>
  <dt>นาฬิกาของอีเวนต์</dt>
  <dd>เวลา ณ สถานที่จัดอีเวนต์: เวลาที่อยู่บนโปสเตอร์</dd>
  <dt>นาฬิกาของคุณ</dt>
  <dd>ช่วงเวลาเดียวกัน ณ ที่ที่คุณอยู่: เวลาที่คุณต้องออกจากบ้าน</dd>
</dl>

> [!IMPORTANT] นาฬิกาของอีเวนต์มาก่อน
> เวลาเริ่มต้นคือเวลาตามนาฬิกาของอีเวนต์เอง ส่วนเวลาของคุณจะถูกคำนวณจากเวลานั้น ไม่ใช่ในทางกลับกัน

::: info ทำไมต้องมีทั้งสองอย่าง
<mark>คนที่อยู่ต่างเมือง</mark>ต้องการทั้งสองอย่าง: เวลาที่อยู่บนโปสเตอร์ และเวลาบนโทรศัพท์ของตัวเอง
:::

## บันทึกครั้งเดียว แสดงได้ทุกภาษา {#stored}

สิ่งที่คุณโพสต์จะถูกบันทึกเป็นข้อมูลดิบ ไม่ใช่ข้อความในภาษาของคุณ: เวลาเริ่มต้นตามนาฬิกาของเมืองนั้นพร้อมเขตเวลาของเมือง ช่วงเวลาเดียวกันในรูปแบบ UTC และจำนวนที่นั่ง หน้าอีเวนต์แต่ละหน้าจะแสดงข้อมูลนี้ใต้หัวข้อ **บันทึกเป็น** ลองสลับภาษาที่ด้านบนดู: ทุกอย่างบนหน้าจะเปลี่ยนไป ยกเว้นกล่องนั้น

| ข้อมูล             | บันทึกเป็น                                   | แสดงเป็น                 |
| ---------------- | ----------------------------------------- | ----------------------- |
| เวลาเริ่มต้น        | `2027-03-06T18:30:00+07:00[Asia/Bangkok]` | ในภาษาของคุณ             |
| เวลาเดียวกันใน UTC | `2027-03-06T11:30:00Z`                    | ไม่แสดง; ใช้สำหรับเรียงลำดับ |
| ที่นั่ง              | `40`                                      | เป็นตัวเลขในภาษาของคุณ     |

::: details หน้าตาของอีเวนต์เมื่อถูกบันทึก
```json {4} :line-numbers
{
  "id": "6f1c…",
  "title": "Night market",
  "starts_at": "2027-03-06T18:30:00+07:00[Asia/Bangkok]",
  "starts_at_utc": "2027-03-06T11:30:00Z",
  "ends_at": "2027-03-06T21:30:00+07:00[Asia/Bangkok]",
  "ends_at_utc": "2027-03-06T14:30:00Z",
  "seats": 40,
  "locale": "th-TH"
}
```
:::

::: danger อย่าบันทึกข้อความที่จัดรูปแบบแล้ว
ข้อความอย่างเช่น "6 มี.ค., 18:30 น." จะถูกต้องเพียงภาษาเดียวและเขตเวลาเดียวเท่านั้น ให้บันทึกข้อมูลดิบแล้วค่อยจัดรูปแบบสำหรับผู้อ่านแต่ละคน:

```ts
const saved = start.toLocaleString("en-US"); // [!code --]
const saved = start.toString(); // [!code ++]
const shown = start.toLocaleString(locale); // [!code focus]
const sorted = start.toLocaleString(); // [!code error]
const guessed = new Date(start.epochMilliseconds); // [!code warning]
```
:::

> [!WARNING] โทรศัพท์บางเครื่องยังไม่มี Temporal
> iPhone ในปัจจุบันยังไม่มี Temporal มาในตัว แอปจึงนำมาใช้งานเองในส่วนนั้น แต่เวลาที่ได้จะเหมือนกัน

> [!CAUTION] การย้ายอีเวนต์ไปยังเมืองอื่น
> การเปลี่ยนเขตเวลาของอีเวนต์จะเปลี่ยนเวลาที่จัดขึ้นสำหรับทุกคน อย่าลืมเปลี่ยนเวลาให้สอดคล้องกันด้วย

คัดลอกบล็อกโค้ดด้วยปุ่มคัดลอก หรือเลือกข้อความแล้วกด <kbd>Ctrl</kbd> + <kbd>C</kbd>

## ส่งอีเมลในภาษาของคุณ {#emails}

เมื่อจองที่นั่ง อีเมลยืนยันจะส่งมาในภาษาที่คุณใช้จอง พร้อมเวลาเริ่มต้นตามนาฬิกาของอีเวนต์ที่เขียนในแบบของคุณ อีเมลแต่ละฉบับจะส่งถึงผู้รับในภาษาของเขาเอง ไม่ว่าใครจะเป็นผู้ดำเนินการ:

| เหตุการณ์ที่เกิดขึ้น    | ใครได้รับอีเมล     | ในภาษาของใคร     |
| ---------------- | --------------- | ---------------- |
| คุณจองที่นั่ง         | คุณ              | ของคุณ ตามที่คุณจอง  |
| คุณโพสต์อีเวนต์      | คุณ พร้อมลิงก์ส่วนตัว | ของคุณ ตามที่คุณโพสต์ |
| หนึ่งวันก่อนจัดงาน    | ทุกคนที่จองไว้      | ของแต่ละคนเอง     |
| ผู้จัดเปลี่ยนแปลงข้อมูล | ทุกคนที่จองไว้      | ของแต่ละคนเอง     |
| ผู้จัดยกเลิกงาน      | ทุกคนที่จองไว้      | ของแต่ละคนเอง     |

ภาษาจะถูกบันทึกไว้พร้อมกับการจอง เช่นเดียวกับภาษาของอีเวนต์ที่บันทึกไว้กับอีเวนต์ และอีเมลจะถูกเขียนขึ้นในภาษานั้น:

```ts
// In short, what src/events/emails.ts does for a booking:
const email = await inLocale(booking.locale, ({ locale, dir }) =>
  fbs(["Your seat at ", fbs.param("event", booking.title)], "Booking email subject"),
);
```

> [!NOTE] ชื่อเรื่องยังคงเป็นภาษาเดิมที่เขียนไว้
> ชื่อของอีเวนต์จะอยู่ในภาษาของผู้จัด ดังนั้นอีเมลภาษาไทยจึงสามารถมีชื่ออีเวนต์เป็นภาษาอาหรับได้ โดยจะมีการระบุภาษาของชื่อนั้นไว้ด้วยเช่นเดียวกับบนหน้าอีเวนต์

หน้า [อีเมล](./emails) แสดงตัวอย่างอีเมลสองฉบับในภาษาของหน้านี้ และสิ่งที่ต้องทำเพื่อให้แต่ละฉบับแสดงผลได้อย่างถูกต้อง รวมถึงการแสดงผลจากขวาไปซ้ายใน Gmail ด้วย

ตั๋วของคุณจะแนบมากับอีเมลยืนยันในรูปแบบ PDF ในภาษาเดียวกัน และคุณสามารถดาวน์โหลดได้จากหน้าอีเวนต์หลังจากจองแล้ว หน้า [PDF](./pdfs) แสดงตัวอย่างตั๋วที่พิมพ์ในภาษาของหน้านี้ พร้อมวิธีการทำงาน
