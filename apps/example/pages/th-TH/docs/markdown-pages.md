# การแปลหน้า markdown

หน้า markdown (`@void/md`) แปลทั้งไฟล์: หนึ่งสำเนาต่อหนึ่งภาษา

## ไฟล์อยู่ที่ไหน

- ต้นฉบับอยู่ใต้ `pages/<source locale>/` เช่น `pages/en-US/blog/hello.md`
- คำแปลแต่ละฉบับอยู่ที่พาธเดียวกันใต้ส่วน URL ของภาษานั้น เช่น
  `pages/th-TH/blog/hello.md` ส่วน URL คือชื่อภาษา เว้นแต่ `vite.config.ts` จะตั้งเป็นอย่างอื่น

## สิ่งที่ต้องแปล

- **ข้อความ:** หัวข้อ ย่อหน้า รายการ ข้อความลิงก์ และข้อความแทนรูปภาพ (alt)
- **ค่าใน frontmatter ที่มีไว้ให้คนอ่าน** (`title`, `description`) คงคีย์ไว้ และคงค่าที่เป็นข้อมูล
  (`date` ตัวเลข slug ชื่อไฟล์) ไว้ตามเดิม

## สิ่งที่ต้องคงไว้ทุกตัวอักษร

- บล็อก `<script>` ด้านบนสุด @void/md ต้องการให้อยู่บรรทัดแรกของไฟล์ และพาธ import ไม่ต้องเปลี่ยน
  เพราะหน้านั้นอยู่ที่ความลึกเท่าเดิมใต้โฟลเดอร์ภาษาอื่น
- คอมโพเนนต์และไอแลนด์ เช่น `<PostMeta />` พร้อม props ของมัน ข้อความในนั้นแปลเองผ่านแค็ตตาล็อกของ fbtee
- บล็อกโค้ด โค้ดในบรรทัด URL และแอตทริบิวต์ HTML
- โครงสร้างของหน้า: หัวข้อและส่วนต่าง ๆ เหมือนกันในลำดับเดียวกัน เพื่อให้ทุกภาษาตรงกัน

## translatedFrom

หน้าที่แปลแล้วแต่ละหน้าบันทึกว่าแปลมาจากต้นฉบับเวอร์ชันใด เป็น `translatedFrom: "<hash>"` ใน
frontmatter ของมัน `void-fbtee check` จะเทียบกับต้นฉบับ และรายงานว่าหน้านั้นล้าสมัยเมื่อต้นฉบับเปลี่ยน

อย่าเขียนค่าแฮชเอง `void-fbtee translate` บันทึกให้สำหรับหน้าที่มันแปล
หลังจากแปลด้วยมือ ให้รัน `void-fbtee stamp pages/<locale>/<path>.md`

สำหรับหน้าที่ล้าสมัย ให้เทียบกับต้นฉบับแล้วแก้เฉพาะส่วนที่เปลี่ยน
