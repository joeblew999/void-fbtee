# การแปลหน้า markdown

หน้า markdown (`@void/md`) แปลทั้งไฟล์: หนึ่งสำเนาต่อหนึ่งภาษา

## ไฟล์อยู่ที่ไหน

- ต้นฉบับอยู่ใต้ `pages/<source locale>/` เช่น `pages/en-US/docs/tour.md`
- คำแปลแต่ละฉบับอยู่ที่พาธเดียวกันใต้ส่วน URL ของภาษานั้น เช่น
  `pages/th-TH/docs/tour.md` ส่วน URL คือชื่อภาษา เว้นแต่ `vite.config.ts` จะตั้งเป็นอย่างอื่น

## สิ่งที่ต้องแปล

- **ข้อความ:** หัวข้อ ย่อหน้า รายการ ข้อความลิงก์ และข้อความแทนรูปภาพ (alt)
- **ค่าใน frontmatter ที่มีไว้ให้คนอ่าน** (`title`, `description`) คงคีย์ไว้ และคงค่าที่เป็นข้อมูล
  (`date` ตัวเลข slug ชื่อไฟล์) ไว้ตามเดิม

## สิ่งที่ต้องคงไว้ทุกตัวอักษร

- บล็อก `<script>` ด้านบนสุด @void/md ต้องการให้อยู่บรรทัดแรกของไฟล์ และพาธ import ไม่ต้องเปลี่ยน
  เพราะหน้านั้นอยู่ที่ความลึกเท่าเดิมใต้โฟลเดอร์ภาษาอื่น
- คอมโพเนนต์และไอแลนด์ เช่น `<EventTime startsAt="…" />` พร้อม props ของมัน: props เป็นข้อมูล
  เหมือนกันทุกสำเนา ข้อความในคอมโพเนนต์แปลเองผ่านแค็ตตาล็อกของ fbtee
- บล็อกโค้ด โค้ดในบรรทัด URL และแอตทริบิวต์ HTML ยกเว้นข้อเดียว: ลิงก์ไปหน้าอื่นของเว็บนี้
  ชี้ไปที่หน้านั้นในภาษาของสำเนา (`/th-TH/events` ในสำเนาภาษาไทย)
- โครงสร้างของหน้า: หัวข้อและส่วนต่าง ๆ เหมือนกันในลำดับเดียวกัน เพื่อให้ทุกภาษาตรงกัน

## วันที่ เวลา และตัวเลข

อย่าเขียนเป็นข้อความ: วันที่ที่เขียนเป็นข้อความก็เป็นแค่ข้อความ ทุกสำเนาต้องทำใหม่ด้วยมือ
และแสดงเวลาของผู้อ่านไม่ได้ ให้ใส่ค่าไว้ในคอมโพเนนต์ที่จัดรูปแบบด้วย `Intl`
โดย import เป็นไอแลนด์ในบล็อก `<script>` หน้าทัวร์ทำแบบนี้ด้วย
`<EventTime startsAt="2027-03-06T18:30:00+07:00[Asia/Bangkok]" />`: แสดงเป็นภาษาของผู้อ่าน
ตามนาฬิกาของกิจกรรมและของผู้อ่าน

สำหรับค่าเดียวมี `<Fmt>` (`components/Fmt.tsx`) หน้านี้ใช้มัน ทุกบรรทัดด้านล่างจึงจัดรูปแบบให้คุณ
เป็นภาษาของหน้านี้:

- ตัวเลข: <Fmt num="1234567.891" />
- เงิน: <Fmt money="1299" currency="THB" />
- เวลาตามนาฬิกาของสถานที่: <Fmt when="2027-03-06T18:30:00+07:00[Asia/Bangkok]" />
- เวลาเดียวกันตามนาฬิกาของคุณ: <Fmt yours="2027-03-06T18:30:00+07:00[Asia/Bangkok]" />
- อีกนานเท่าไร: <Fmt ago="2027-03-06T18:30:00+07:00[Asia/Bangkok]" />
- ชื่อภาษาในภาษาของคุณ: <Fmt langs />

## translatedFrom

หน้าที่แปลแล้วแต่ละหน้าบันทึกว่าแปลมาจากต้นฉบับเวอร์ชันใด เป็น `translatedFrom: "<hash>"` ใน
frontmatter ของมัน `void-fbtee check` จะเทียบกับต้นฉบับ และรายงานว่าหน้านั้นล้าสมัยเมื่อต้นฉบับเปลี่ยน

อย่าเขียนค่าแฮชเอง `void-fbtee translate` บันทึกให้สำหรับหน้าที่มันแปล
หลังจากแปลด้วยมือ ให้รัน `void-fbtee stamp pages/<locale>/<path>.md`

สำหรับหน้าที่ล้าสมัย ให้เทียบกับต้นฉบับแล้วแก้เฉพาะส่วนที่เปลี่ยน
