# فعاليات تعرف الوقت في مكانك

[[toc]]

انشر فعالية في مدينتك. أي شخص، في أي مكان، سيرى متى تبدأ بتوقيت **ساعتك** وبتوقيت
**ساعته**، بلغته الخاصة. لا حسابات لفروق التوقيت، ولا "هل هذه الساعة 7 مساءً بتوقيتي أم بتوقيتك؟". {.lead}

![شعار The Void](/void.svg)

## جرّبها {#try-it}

1. انشر فعالية بلغتك الخاصة.
2. بدّل اللغة من الأعلى: الفعالية تتبعك.
3. احجز مقعدًا :tada:

> [!TIP] منطقتك الزمنية
> هذه الصفحة تعرف منطقتك الزمنية من متصفحك: <span data-your-zone></span>.

## انشرها بلغتك {#post}

اكتب العنوان والوصف بالطريقة التي تقولها بها. يراها القراء كما كتبتها، وموسومة
باللغة المكتوبة بها، حتى يقرأها متصفحهم وقارئ الشاشة بشكل صحيح.

::: tip اكتبها كما تقولها
استخدم كلماتك الخاصة وطريقتك الخاصة في كتابة التواريخ. يرى القراء كلماتك كما كتبتها.
:::

::: warning اختر مدينة الفعالية
حدد المدينة التي تقام فيها الفعالية، وليس المدينة التي تتواجد فيها الآن. يتم حساب كل الأوقات انطلاقًا
منها.
:::

> [!NOTE] اللغة تُحفظ أيضًا
> تسجّل كل فعالية اللغة التي كُتبت بها، حتى يقرأها متصفح القارئ وقارئ الشاشة
> بتلك اللغة، أيًا كانت لغة الصفحة المحيطة بها.

## كل وقت، مرتين {#times}

تعرض كل فعالية متى تقام، من بدايتها إلى نهايتها، في مكان إقامتها، ومرة أخرى بتوقيت
ساعتك الخاصة، وكم تبقى عليها.
يتم حساب التوقيت الصيفي لتاريخ الفعالية، وليس لليوم.[^dst] إليك السوق الليلي
في بانكوك، بلغتك ومنطقتك الزمنية:

<EventTime startsAt="2027-03-06T18:30:00+07:00[Asia/Bangkok]" endsAt="2027-03-06T21:30:00+07:00[Asia/Bangkok]" />

<dl>
  <dt>توقيت الفعالية</dt>
  <dd>الوقت في مكان إقامة الفعالية: ما هو مكتوب على الملصق.</dd>
  <dt>توقيتك</dt>
  <dd>نفس اللحظة في مكانك: متى تحتاج إلى مغادرة المنزل.</dd>
</dl>

> [!IMPORTANT] توقيت الفعالية يأتي أولًا
> وقت البداية هو الوقت بتوقيت الفعالية نفسها. توقيتك يُحسب منه، وليس العكس
> أبدًا.

::: info لماذا الاثنان
<mark>شخص في مدينة أخرى</mark> يحتاج إلى كليهما: الوقت المكتوب على الملصق، والوقت على هاتفه
الخاص.
:::

## تُحفظ مرة واحدة، وتُعرض بكل لغة {#stored}

ما تنشره يُحفظ كبيانات مجردة، وليس كنص بلغتك: وقت البداية بتوقيت مدينتها
مع المنطقة الزمنية للمدينة، ونفس اللحظة بالتوقيت العالمي المنسق (UTC)، وعدد المقاعد. تعرض صفحة كل فعالية
ذلك تحت **محفوظة كـ**. بدّل اللغة من الأعلى: كل شيء في الصفحة يتغير، باستثناء
هذا الصندوق.

| ماذا             | محفوظة كـ                                 | تُعرض كـ         |
| ---------------- | ----------------------------------------- | --------------- |
| البداية          | `2027-03-06T18:30:00+07:00[Asia/Bangkok]` | بلغتك           |
| نفس الوقت بـ UTC | `2027-03-06T11:30:00Z`                    | لا تُعرض؛ للترتيب |
| المقاعد          | `40`                                      | بأرقام لغتك     |

::: details كيف تبدو الفعالية وهي محفوظة
```json {4} :line-numbers
{
  "id": "6f1c…",
  "title": "Night market",
  "starts_at": "2027-03-06T18:30:00+07:00[Asia/Bangkok]",
  "starts_at_utc": "2027-03-06T11:30:00Z",
  "ends_at": "2027-03-06T21:30:00+07:00[Asia/Bangkok]",
  "ends_at_utc": "2027-03-06T14:30:00Z",
  "seats": 40,
  "locale": "th-TH"
}
```
:::

::: danger لا تحفظ أبدًا نصًا منسقًا
نصوص مثل "6 Mar, 6:30 pm" صحيحة فقط في لغة واحدة ومنطقة زمنية واحدة. احفظ البيانات
ونسّقها لكل قارئ:

```ts
const saved = start.toLocaleString("en-US"); // [!code --]
const saved = start.toString(); // [!code ++]
const shown = start.toLocaleString(locale); // [!code focus]
const sorted = start.toLocaleString(); // [!code error]
const guessed = new Date(start.epochMilliseconds); // [!code warning]
```
:::

> [!WARNING] بعض الهواتف لا تدعم Temporal بعد
> هواتف iPhone الحالية لا تحتوي على Temporal مدمجًا، لذا يجلب التطبيق نسخته الخاصة هناك. الأوقات
> هي نفسها.

> [!CAUTION] نقل فعالية إلى مدينة أخرى
> تغيير المنطقة الزمنية للفعالية يغيّر وقت إقامتها للجميع. غيّر الوقت معها.

انسخ كتلة برمجية بزرها، أو حددها واضغط <kbd>Ctrl</kbd> + <kbd>C</kbd>.

## تُرسل بالبريد الإلكتروني بلغتك {#emails}

احجز مقعدًا، وسيصلك التأكيد باللغة التي حجزت بها، مع كتابة وقت البداية بتوقيت
الفعالية بطريقتك. كل بريد إلكتروني يصل إلى الشخص بلغته الخاصة، أيًا كان من تسبب
في إرساله:

| ما يحدث             | من يتلقى بريدًا إلكترونيًا | بلغة من        |
| ------------------- | ------------------------ | -------------- |
| تحجز مقعدًا          | أنت                      | لغتك، كما حجزت |
| تنشر فعالية         | أنت، مع رابطها الخاص     | لغتك، كما نشرت |
| في اليوم السابق لها | كل من حجز                | كل شخص بلغته   |
| يغيّرها المنظّم       | كل من حجز                | كل شخص بلغته   |
| يلغيها المنظّم       | كل من حجز                | كل شخص بلغته   |

تُحفظ اللغة مع الحجز، كما تُحفظ لغة الفعالية مع الفعالية، ويُكتب البريد الإلكتروني
بها:

```ts
// In short, what src/events/emails.ts does for a booking:
const email = await inLocale(booking.locale, ({ locale, dir }) =>
  fbs(["Your seat at ", fbs.param("event", booking.title)], "Booking email subject"),
);
```

> [!NOTE] يبقى العنوان كما كُتب
> عنوان الفعالية يكون بلغة منظّمها، لذا يمكن لبريد إلكتروني تايلاندي أن يحمل عنوانًا عربيًا. وهو
> موسوم بلغته الخاصة هناك أيضًا، كما في صفحة الفعالية.

تعرض [صفحة رسائل البريد الإلكتروني](./emails) رسالتين منها، بلغة هذه الصفحة، وما يتطلبه وصول كل منهما
بالاتجاه الصحيح، بما في ذلك من اليمين إلى اليسار في Gmail.

تأتي تذكرتك مع التأكيد كملف PDF، بنفس اللغة، ويمكنك تنزيلها
من صفحة الفعالية بمجرد الحجز. تعرض [صفحة ملفات PDF](./pdfs) واحدة، مطبوعة بلغة هذه الصفحة،
وكيف يتم ذلك.
